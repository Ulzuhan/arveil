# Bundled fonts

Arveil ships its typefaces inside the app so that nothing is fetched at
runtime. All three families are licensed under the SIL Open Font License 1.1;
each license is bundled next to its font and registered with Flutter's
license page at startup.

| File | Family and role | Source file |
| --- | --- | --- |
| `Newsreader-VF.ttf` | Newsreader, screen titles | `ofl/newsreader/Newsreader[opsz,wght].ttf` |
| `InstrumentSans-VF.ttf` | Instrument Sans, interface text | `ofl/instrumentsans/InstrumentSans[wdth,wght].ttf` |
| `IBMPlexMono-Regular.ttf` | IBM Plex Mono, identifiers | `ofl/ibmplexmono/IBMPlexMono-Regular.ttf` |
| `IBMPlexMono-Medium.ttf` | IBM Plex Mono, safety numbers | `ofl/ibmplexmono/IBMPlexMono-Medium.ttf` |
